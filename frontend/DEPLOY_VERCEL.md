# راهنمای دیپلوی فرانت‌اند روی Vercel (پلن رایگان)

فرانت‌اند یک اپ Next.js است و Vercel (سازنده‌ی خود Next.js) بهترین و ساده‌ترین جای رایگان برای اجرای آن است.

> ⚠️ **ترتیب مهم است**: اول بک‌اند را روی Render بالا بیاورید و آدرسش را داشته باشید ([`../backend/DEPLOY_RENDER.md`](../backend/DEPLOY_RENDER.md))، چون فرانت‌اند باید بداند به کدام آدرس API وصل شود. راهنمای کلی ترتیب کارها در [`../DEPLOY.md`](../DEPLOY.md).

## ۱. ساخت پروژه در Vercel
1. به [vercel.com](https://vercel.com) بروید و با گیت‌هاب وارد شوید.
2. **Add New… → Project** را بزنید.
3. ریپازیتوری `mozhgankia/Client_tracker` را import کنید.
4. در صفحه‌ی تنظیمات پروژه:
   | فیلد | مقدار |
   |---|---|
   | **Root Directory** | ⚠️ **حتماً روی `frontend` بگذارید** (روی **Edit** بزنید و این پوشه را انتخاب کنید) |
   | **Framework Preset** | `Next.js` (خودش تشخیص می‌دهد) |
   | **Build Command** | پیش‌فرض (`next build`) — دست نزنید |
   | **Output Directory** | پیش‌فرض — دست نزنید |

   > ‼️ **مهم‌ترین تنظیم اینجا `Root Directory` است.** ریشه‌ی ریپازیتوری یک `package.json` قدیمی (مربوط به اسکریپت‌های ربات) دارد که Next.js نیست. اگر Root Directory را روی `frontend` نگذارید، Vercel آن `package.json` ریشه را می‌بیند و با خطای `No Output Directory named "out" found` شکست می‌خورد. فایل `frontend/vercel.json` هم که در ریپو هست، بعد از تنظیم Root Directory، فریم‌ورک را صریحاً Next.js اعلام می‌کند.

## ۲. متغیر محیطی (مهم‌ترین قدم)
پایین همان صفحه، بخش **Environment Variables**:

| Name | Value |
|---|---|
| `NEXT_PUBLIC_API_BASE_URL` | آدرس بک‌اند روی Render، مثلاً `https://maskanyar-backend.onrender.com` (بدون `/` در انتها) |

> بدون این متغیر، فرانت‌اند نمی‌داند API کجاست و همه‌ی درخواست‌ها شکست می‌خورند. آدرس Render را از داشبورد Render بردارید (بعد از اینکه بک‌اند اولین بار دیپلوی شد).

## ۳. Deploy
**Deploy** را بزنید. بعد از یکی-دو دقیقه، Vercel یک آدرس به شما می‌دهد (چیزی مثل `https://client-tracker-xxxx.vercel.app`). این **آدرس فرانت‌اند** شماست.

## ۴. سیم‌کشی برگشتی به Render (حیاتی)
حالا باید بک‌اند بداند که به این آدرس Vercel اجازه‌ی دسترسی بدهد (وگرنه مرورگر به‌خاطر CORS همه را بلاک می‌کند):

1. به داشبورد **Render** برگردید → سرویس بک‌اند → **Environment**.
2. مقدار `CORS_ORIGIN` را برابر با آدرس Vercel خود بگذارید، مثلاً:
   ```
   CORS_ORIGIN=https://client-tracker-xxxx.vercel.app
   ```
   اگر می‌خواهید preview deploy‌های Vercel هم کار کنند، با کاما جدا کنید:
   ```
   CORS_ORIGIN=https://client-tracker-xxxx.vercel.app,https://client-tracker-git-main-xxxx.vercel.app
   ```
3. ذخیره کنید — Render خودکار ری‌استارت می‌شود.

## ۵. تست نهایی
آدرس Vercel را در مرورگر باز کنید:
1. باید صفحه‌ی **ورود** را ببینید (به زبان فارسی، راست‌به‌چپ).
2. **ثبت‌نام** کنید (ایمیل + رمز).
3. وارد داشبورد شوید و یک **مشتری جدید** بسازید → باید بلافاصله در لیست ظاهر شود (یعنی به Supabase واقعی نوشته شد).
4. سوییچ زبان (فا/EN/عربی) و تم تیره/روشن را امتحان کنید.

اگر مرحله ۳ کار کرد، یعنی کل زنجیره **Vercel → Render → Supabase** زنده و سالم است. 🎉

## نکات پلن رایگان Vercel
- **بی‌نهایت دیپلوی، بدون خواب**: برخلاف Render، فرانت‌اند Vercel هیچ‌وقت نمی‌خوابد (استاتیک است).
- **دیپلوی خودکار**: هر بار که به برنچ push کنید، Vercel خودکار دوباره build و دیپلوی می‌کند.
- **دامنه‌ی اختصاصی**: بعداً می‌توانید یک دامنه‌ی دلخواه (مثلاً `app.yourdomain.com`) رایگان وصل کنید — یادتان باشد آن آدرس را هم به `CORS_ORIGIN` بک‌اند اضافه کنید.
